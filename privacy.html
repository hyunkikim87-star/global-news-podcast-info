개인정보처리방침

최종 수정: 2026-10-28

이 방침은 개인 영어학습용 Hyunki Global News Podcast의 Google 계정 연결 및 결과 저장에 적용됩니다.

접근하는 정보와 이용 목적

Google OAuth의 drive.file 범위를 사용하여 앱이 생성했거나 사용자가 접근을 허용한 파일·폴더의 식별자, 이름, 형식 및 업로드 검증에 필요한 메타데이터를 처리합니다. 목적은 생성한 뉴스 MP3와 출처·대본 JSON을 지정 폴더에 저장하고, 중복 및 파일 무결성을 확인하는 것입니다. 전체 Drive 검색이나 관련 없는 개인 문서 열람은 목적으로 하지 않습니다.

인증정보 및 저장

승인 시 OAuth 접근·갱신 토큰이 생성됩니다. 무인 실행을 위해 인증정보는 운영자가 관리하는 로컬 인증 파일 또는 비공개 GitHub Actions Secrets에 보관합니다. 이 공개 사이트와 공개 저장소에는 인증정보를 넣지 않습니다. 생성 결과는 개인 Drive에 남으며, 실패 시 복구용 생성 파일은 GitHub Actions 아티팩트에 설정상 7일 보관될 수 있습니다. Drive 결과는 사용자가 삭제할 때까지 남습니다.

외부 서비스

대본 생성·검수에는 Google Gemini API, 음성 변환에는 Microsoft Edge의 음성 서비스를 사용하는 라이브러리, 실행에는 GitHub Actions를 이용하도록 설계되어 있습니다. 이 서비스에는 처리에 필요한 공개 뉴스 자료와 생성 대본이 전달됩니다. Drive의 관련 없는 개인 문서를 대본 생성 서비스에 전송하도록 설계하지 않았습니다. 서비스 제공자는 각자의 정책에 따라 데이터를 처리할 수 있습니다.

공유 및 사용 제한

Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. Google API에서 받은 정보의 이용 및 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수해야 합니다. 인증 토큰은 기능 수행에 필요한 Google 인증·Drive 요청에만 사용합니다.

연결 해제와 삭제

Google 계정의 서드 파티 연결 관리에서 앱 접근을 철회할 수 있습니다. 철회만으로 이미 저장된 Drive 파일이나 로컬 인증 파일, GitHub Secrets가 자동 삭제되지는 않습니다. 운영자는 해당 저장 위치에서 이를 별도로 삭제할 수 있습니다. 운영자가 보관하는 정보 삭제에 대한 문의는 아래 연락처로 요청할 수 있습니다.

이 사이트 및 문의

이 사이트는 GitHub Pages에서 제공하는 정적 안내 페이지이며 별도의 로그인, 입력 폼, 분석 추적 스크립트를 두지 않습니다. 호스팅 제공자인 GitHub는 자체 정책에 따라 접속 정보를 처리할 수 있습니다.
